- **Статус:** Виконано.

### Етап 2: Винесення локалізації (`I.uk` та `I.en`)
- **Що потрібно зробити:**
  1. Створити папку `js/` (якщо ще немає).
  2. Винести об'єкт перекладів `const I = { en: {...}, uk: {...} };` із `index.html` у `js/i18n.js`.
  3. Підключити `<script src="./js/i18n.js"></script>` у `<head>` `index.html` перед основним скриптом.
  4. Додати `'./js/i18n.js'` у масив `SHELL` у `sw.js` (для офлайн-кешування PWA).
  5. Перевірити, що всі переклади працюють і Playwright тести проходять.
- **Увага:** Не видаляти жодного ключа перекладу! Паритет між `uk` та `en` має бути 100%.

### Етап 3: Винесення чистих математичних розрахунків (Domain)
- **Що потрібно зробити:**
  1. Знайти в `index.html` чисті функції розрахунків: перерахунок порцій, пропорційне масштабування складної страви, нормалізація активних інгредієнтів, розрахунок калорій і БЖВ.
  2. Винести їх у `js/calc-nutrition.js`.
  3. Підключити через `<script src="./js/calc-nutrition.js"></script>` у `index.html`.
  4. Додати `'./js/calc-nutrition.js'` у `SHELL` у `sw.js`.
  5. Створити легкий швидкий unit-тест `tests/unit/calc.test.mjs` на чистому Node.js (запуск через `node tests/unit/calc.test.mjs`).

### Етап 4: Винесення AI-провайдерів та промптів
- **Що потрібно зробити:**
  1. Винести тексти промптів (дієтолог, аналіз прийому, аналіз дня, парсинг JSON) та клієнти провайдерів (Gemini, Groq, OpenAI, Claude, xAI) у `js/ai-service.js`.
  2. Підключити через `<script src="./js/ai-service.js"></script>`.
  3. Додати у `sw.js`.
  4. Перевірити збереження API ключів у `localStorage` (не змінювати ключі!).

### Етап 5: Винесення CSS стилів
- **Що потрібно зробити:**
  1. Винести правила із `<style>` у `css/main.css` та адаптивні правила у `css/responsive.css`.
  2. Підключити через `<link rel="stylesheet" href="./css/main.css">` та `<link rel="stylesheet" href="./css/responsive.css">`.
  3. Оновити кеш у `sw.js`.
  4. Перевірити відображення на ширині 360px та модальні вікна.

### Етап 6: Інструкція для AI в `AGENTS.md`
- **Що потрібно зробити:**
  1. Отримати прямий дозвіл власника на доповнення `AGENTS.md`.
  2. Додати правила маршрутизації задач: яку задачу в яких файлах вирішувати, щоб не читати зайві модулі.
  3. Видалити `OPTIMIZATION_PROGRESS.md` після завершення всього циклу.
