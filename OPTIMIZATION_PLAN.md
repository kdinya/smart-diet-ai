# План оптимізації репозиторію Smart Diet AI

Цей документ фіксує покроковий план покращення архітектури репозиторію для швидкої, стабільної та економної (за токенами) роботи штучного інтелекту.

---

## Головні інваріанти (непорушні правила)
1. **Безпека даних користувачів**: Жодних змін у форматі `localStorage` (`smartdiet-v1`, `smartdiet-sync-queue`, історія, профілі, синхронізація). Старі та нові клієнти повинні працювати без втрати жодного запису.
2. **Дизайн та інтерфейс**: Жодних візуальних змін або регресій у верстці, кольорах, відступах чи UI-компонентах.
3. **Функціонал та PWA**: Повна працездатність офлайн, актуальність кешу Service Worker, успішне проходження `npm run check` та `npm run test:unit` на кожному етапі.
4. **Стабільність ванільної архітектури**: Відмова від надмірного дроблення на мікрофайли та відмова від сторонніх бандлерів (Vite/Webpack), які ламають роботу ванільного PWA.
